# 🧠 解題思路心法

## 卡題時的思考流程

1. **暴力解** → 想出最直觀的解法（哪怕是 O(n³)）
2. **找重複計算** → 有沒有東西被算了多次？ → DP/Memoization
3. **找規律** → 有沒有單調性？ → Binary Search / Two Pointers
4. **換角度** → 從結果往回推？從小問題往上堆？
5. **類比** → 像哪道你做過的題？

---

## 題型識別關鍵字

| 關鍵字 | 可能解法 |
|--------|----------|
| 最短路/最少步數 | BFS |
| 所有可能/組合/排列 | Backtracking |
| 最大/最小值 + 可行性 | Binary Search on Answer |
| 子陣列/子字串 + 限制 | Sliding Window |
| 有序 + 兩個條件 | Two Pointers |
| 需要頻繁取最值 | Heap |
| 計數/頻率 | Hash Map |
| 前綴和/區間查詢 | Prefix Sum |
| 樹形問題 | DFS（後序居多） |
| 連通性 | Union-Find |

---

## DP 識別

- 求**最大/最小值**
- 求**計數/方案數**
- 求**是否可行**（bool）
- 問題可以**分解為子問題**

DP 就是 DFS + Memoization + 找 base case。

---

## 時間緊迫時的策略

1. 先說出 Brute Force 的思路
2. 分析瓶頸在哪（哪段最慢）
3. 針對瓶頸優化（排序？Hash？DP？）
4. 不確定時就說「我想到了 X 方法，複雜度是 Y，還有更好的嗎？」

---

## 反思習慣

每道題做完問自己：
- 這題的核心 insight 是什麼？
- 如果換一個條件，解法會怎麼變？
- 有沒有更簡潔的寫法？

# ✅ 面試解題 Checklist

## 收到題目後（2 分鐘）

- [ ] 看清楚題意，確認輸入輸出格式
- [ ] 詢問邊界：`n=0`, `n=1`, 負數, 重複值？
- [ ] 確認資料範圍（決定複雜度上限）
- [ ] 能否有額外空間？

---

## 設計解法（5 分鐘）

- [ ] Brute force 先說出來（不管對不對）
- [ ] 從 brute force 找優化方向
- [ ] 說出時間/空間複雜度
- [ ] 得到面試官確認再開始寫

---

## 實作（15 分鐘）

- [ ] 先寫函數簽名和主要邏輯骨架
- [ ] 邊寫邊說出思路
- [ ] 先讓程式跑起來，再做優化
- [ ] 變數命名清晰

---

## 測試（5 分鐘）

- [ ] 手動追蹤一個 example
- [ ] 邊界測試：空輸入、單元素、最大值
- [ ] 如有 bug，冷靜 debug 不要慌

---

## 常見坑

| 坑 | 解法 |
|----|------|
| 整數溢位 | Python 不用擔心，其他語言用 long |
| 陣列越界 | 寫之前想好邊界 |
| 修改輸入 | 先問面試官能否修改 |
| 忘記 base case | DP/遞迴必查 |
| 無限循環 | 確保每次迭代都縮小問題規模 |
